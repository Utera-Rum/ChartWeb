# ChartWeb

bitbank のチャートと売買判定を、iPhone などのスマホのブラウザで見る Web 版。
[chartapp](../chartapp)（PCのデスクトップアプリ）の判定ロジックを JavaScript に移したもの。
ビルド不要の静的サイト（`web/` の中身をそのまま置くだけ）なので、PCを起動していなくても使える。

Ultera Builder で作成（テンプレート: minimal）。

## できること
- 銘柄（bitbank の円建て全銘柄）と時間足（1m〜1w）の切り替え。ローソク足・出来高・MA（5/20/100/200）・ボリンジャーバンド
- 売買判定（買い / 売り / 買い寄り / 売り寄り / 様子見）、スコア、ルールごとの理由、売買シグナルの印
- 下のチャート: RSI / MACD / スコア。チャートをタップするとその足の判定内訳を表示
- 判定ルール・基準値の設定（⚙）。設定はブラウザに保存
- 15秒ごとに自動更新（画面を見ているときだけ）

## できないこと（意図して入れていない）
- **プッシュ通知**: iPhone の Web アプリは、サーバーを用意しないと通知を送れない。通知は既存の Discord（chartapp の `cloud_check.py`）を使う
- **保有資産・取引履歴**: APIキーをスマホやWebページに置かないため。PC の chartapp で見る
- **描画ツール**（トレンドライン等）

## 使い方
### パソコンで試す
```
cd Z:\UlteraProjects\ChartWeb\web
python -m http.server 8000
```
ブラウザで http://localhost:8000/ を開く。

### iPhone で使う
Web に公開する必要がある（同じ Wi-Fi 内の PC を見せる方法もあるが、PC が必要になる）。
公開したら iPhone の Safari で開き、共有ボタン →「ホーム画面に追加」でアプリのように使える。

### 公開（GitHub Pages）
`.github/workflows/pages.yml` が `web/` をそのまま公開する。リポジトリを GitHub に作って push し、
Settings → Pages → Source を **GitHub Actions** にする。
- 公開されるのはチャートの画面だけ（データは bitbank の公開APIをブラウザが直接読む）。APIキーや個人情報は含まれない
- 無料プランでは、Pages で公開できるのは公開リポジトリだけ（URLを知っていれば誰でも見られる）

## テスト
`tests/parity.html` を開くと、JS版の計算が chartapp（Python）版と一致するか、データ取得の部品が正しいかを調べる。
```
cd Z:\UlteraProjects\ChartWeb
python -m http.server 8766
```
http://localhost:8766/tests/parity.html を開き、タイトルが `PARITY OK` ならすべて合格。

正解データ（`tests/fixture.json`）は chartapp の `indicators.py` / `signals.py` で作る。chartapp の判定を変えたら作り直す。
```
Z:\UlteraProjects\chartapp\.venv\Scripts\python.exe tests\make_fixture.py
```

## メモ
- チャート部品は Lightweight Charts 4.2.0（jsDelivr から読み込み。`integrity` で改ざんを検出）
- 時間は日本時間で表示（チャートはUTC表示なので内部で9時間足している）
- bitbank のローソク足APIは、1時間足以下が日付（YYYYMMDD）、4時間足以上が年（YYYY）で指定する
- 判定は確定した足（最新の足は形成中なので除く）で行う
- 売買判定は目安で、投資の助言ではない
